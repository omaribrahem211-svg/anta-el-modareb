# أنت المدرب

لعبة مسيرة مدرب كرة قدم: تبدأ من الدرجة الرابعة وتوصل لقمة العالم. تختار تشكيلتك وخطتك وتتفرج على الماتش من لوحة المدرب (أو 3D) وتغيّر وإنت بتتفرج.

- الكود: `www/` (JavaScript بدون build)، والـ Android عن طريق Capacitor (`android/`).
- `npm install && npm run sync` ينسخ خط Changa ويزامن مشروع الأندرويد.
- النسخة القديمة (React) محفوظة في الفرع `legacy-react` وعلامة `legacy-react-4d7999c`.
- المسيرات المحفوظة من النسخة القديمة بتتنقل من زرار «كمّل مسيرتك القديمة» في الشاشة الرئيسية.
